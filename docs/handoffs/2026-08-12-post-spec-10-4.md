## Gotchas discovered this session

**Tooling**

- **`npm pack --json` changed shape in npm 12** — an array of results became an object keyed by package name. `test/packaging.test.ts` destructured index 0 and threw. CI stayed green only because its bundled npm is older, so the check was one runner-image bump from breaking with no commit to blame. Fixed to accept both and throw on a third.
- **Local `npm` is ahead of CI's.** `npm` here is `~/.vite-plus/bin/npm` — vite-plus's Node 24.19.0 toolchain, bundling **npm 12.0.2**. `setup-node` installs a Node 24 whose npm is still 11.x. Local is the future; treat a local-only failure as early warning, not noise.
- **`pnpm exec <tool>` prints `Already up to date` on stdout**, which corrupts anything piped into a JSON parser. Strip to the first `{` or `[`.

**eslint / antfu**

- **9.1.0 taught `unicorn/filename-case` to report directory names separately.** Nine `[podcastId]`/`[teamId]` server routes in nuxt-kickstart failed on names that cannot change without renaming the route params they declare. uxlab had already hit the same nine at 9.2.0; its anchored `'^\\[([a-zA-Z0-9]+)\\]$'` entry was lifted verbatim, so the two configs converged.
- The anchoring is load-bearing: `ignore` entries test **every path segment**, so an unanchored version also matches any file whose name merely contains brackets, making the two filename patterns above it dead config.
- 9.2.0 → 9.3.0 is **one line** — `erasable-syntax-only` moving from an inlined chunk to a package import. No rule changes.

**Vue / a11y**

- **None of uxlab's clickable rows could simply become buttons** — each already contains one (Clear, Mark Done, Browse files), and buttons do not nest. Hence heading-wrapping-a-button for the accordion, and a stretched `::after` target for the habit card.
- **`<h3>` inside `<button>` is invalid** — button content is phrasing content. The WAI-ARIA accordion shape is heading *outside*, button *inside*.
- **Four of the 19 a11y hits were the rule being wrong, not a defect.** Two modal backdrops that already close on Escape, a `@mousemove` presentation container, and a heatmap where per-cell focus would build a **~365-stop tab trap**. Disabled inline with reasons, matching the repo's `vue/no-v-html` style.

**CI**

- **`pnpm run test:unit` passes `--project unit` and does not run `test/nuxt/`.** Only `test:coverage` runs everything. #73 broke `test/nuxt/history-panel.test.ts` and local runs stayed green — the previous handoff warned about this exact trap and it still caught us. **Run `pnpm run test:coverage` before pushing uxlab.**

**Carried forward, still true:** `commitlint --from X --to Y` is unreliable — lint one commit at a time via stdin. `pnpm add` does not re-run `prepare`. `@commitlint/types` is a phantom dependency in both consumers. A runner-allocation failure looks exactly like a test failure (`gh run rerun <id> --failed`). zsh expands `--include=*.ts` and `app/pages/*/[...slug].vue` before git/grep see them — quote them. `rm` is aliased to prompt; `timeout` is not installed.
